# Your game input (ignored by Git)

Put your USA retail ISO (`SLUS_213.76`) here, then ask your coding agent to follow [AGENTS.md](../AGENTS.md).
Setup extracts and verifies only the boot executable and preserves the ISO. With multiple ISOs, use `--iso PATH`.
An ISO stored elsewhere also works with that option. See the [setup reference](../docs/setup.md#game-input).

An already extracted executable goes at `orig/SLUS_213.76/SLUS_213.76`. Its directory's README gives the expected size
and SHA-256. Only the READMEs and `.gitkeep` placeholder are tracked.
