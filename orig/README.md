# Original executables (not in the repository)

One directory per version, named by the boot game ID, each holding the retail boot executable of that version:
`orig/SLUS_213.76/SLUS_213.76`, `orig/SLES_538.86/SLES_538.86`, `orig/SLES_540.30/SLES_540.30`,
`orig/SLKA_253.72/SLKA_253.72` and `orig/SLPM_663.54/SLPM_663.54`. Each directory's README gives the expected size and
SHA-256. You need to provide your own copy; the repository contains no game data. Only the READMEs and `.gitkeep` files
are tracked.
