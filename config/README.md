# config/

Committed build inputs and evidence files. "By hand" means contributors edit the file in a normal commit; "generated"
means a tool writes it and you rerun the tool instead of editing (the tool is named).

## Shared by all versions

| File | What it is | Edited |
| --- | --- | --- |
| `versions.json` | The five supported releases: region, boot executable name, executable and disc image hashes | by hand |
| `tus_overrides.yaml` | Hand corrections that `tools/build/tus.py map` applies on top of its evidence when `ninja` generates the translation-unit map (`build/SLUS_213.76/tus.yaml`) | by hand |
| `toolchain-compilers.json` | Pinned compiler archives (URLs, SHA-256) that `tools/toolchain.py` downloads | by hand, when a pin changes |
| `toolchain-assemblers.json` | Pinned assembler hashes, including the patched `ps2eeas` | by hand, when a pin changes |
| `toolchain-binutils.json` | Pinned Debian binutils packages for MIPS | by hand, when a pin changes |
| `toolchain-local.json` | Pinned `wibo` release used to run the Windows tools | by hand, when a pin changes |
| `vu0_math.json` | Which VU0 math operations of `include/ps2/vu0_math.h` have two exact source consumers | by hand (`tools/studies/verify_vu0_math.py` checks it) |

## Per version, `config/<GAME_ID>/`

Every version has `boundaries.txt`, `checksums.sha256`, `layout.json` and `splat.yaml`. Only `SLUS_213.76` has recovered
source, so only it has the rest.

| File | What it is | Edited |
| --- | --- | --- |
| `splat.yaml` | splat configuration derived from the ELF section table | generated by `tools/build/splat_config.py` |
| `layout.json` | ELF header, program headers and section records the packer reproduces | generated by `tools/build/elf_layout.py` |
| `checksums.sha256` | SHA-256 the rebuilt executable must have | by hand (never changes for a release) |
| `boundaries.txt` | Function starts splat cannot see; `// explicit:` lines are hand-listed with a reason | `tools/maint/boundaries.py` writes it, the explicit lines by hand |
| `splits.yaml` | The split list: which source file covers which address range, with flags (docs/units.md) | by hand |
| `symbols.txt` | Names: bound (mangled) names, names the code uses, and `alias` lines that never change linking | by hand and `tools/autodecomp.py register` |
| `equivalent.yaml` | Functions of the `equivalent` evidence tier and their evidence | by hand and `tools/autodecomp.py register` |
| `libraries.txt` | Which library (a directory of `src/`) each stretch of `.text` belongs to, and where the link-once block is; progress, file placement and the TU map use it | by hand |
| `class_method_abi.json` | Verified method ABI evidence (return, parameters, fields) that `tools/maint/class_skeletons.py` turns into `include/*/classes/` | by hand |
| `rtti_abi.json` | Verified GCC 2.95 RTTI helper ABI seeds for `tools/maint/rtti_evidence.py` and `tools/maint/class_skeletons.py` | by hand |
| `ps2_header_evidence.json` | Which `include/ps2/` headers are verified by which exact source functions (checked by `tools/maint/shared_context.py`) | by hand |
| `native_header_evidence.json` | The same for the native header views (camera, weapons, arms, effects; docs/native-headers.md, checked by `tools/maint/mod_context.py`) | by hand |
